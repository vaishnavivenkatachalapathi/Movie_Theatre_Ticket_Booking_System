# Generated Visualizations
## Movie Theatre Ticket Booking and Box Office Analysis System
### Course Code: 25ITC31 - Foundations of Data Science

The visualizations in this folder are available in **SVG (Scalable Vector Graphics)** for direct rendering in GitHub/Markdown, in **PNG format** via Python Matplotlib/Seaborn, and interactively via **[interactive_dashboard.html](interactive_dashboard.html)**:

1. **`1_movie_revenue_comparison.svg`**  
   - Type: Grouped Bar Chart  
   - Features: Displays Gross Revenue vs. Net Revenue for each movie title, highlighting the financial impact of cancellations and refunds.

2. **`2_genre_revenue_distribution.svg`**  
   - Type: Donut Chart / Pie Chart  
   - Features: Illustrates proportional net revenue contributions across Sci-Fi, Action, Drama, and Historical Drama.

3. **`3_screen_occupancy_boxplot.svg`**  
   - Type: Seaborn Box Plot with Stripplot Overlay  
   - Features: Highlights median, interquartile range (IQR), and spread of occupancy percentage across individual auditorium screens.

4. **`4_correlation_heatmap.svg`**  
   - Type: Annotated Pearson Correlation Heatmap  
   - Features: Displays linear correlation coefficients ($r$) between ticket price, ticket volume, gross amount, refunds, net revenue, and occupancy rate.

5. **`5_price_vs_occupancy_scatter.svg`**  
   - Type: Scatter Plot with Linear Regression Trendline  
   - Features: Analyzes price elasticity and consumer willingness to pay for premium screen formats.

6. **`6_timeslot_occupancy.svg`**  
   - Type: Categorical Bar Chart  
   - Features: Compares average theatre occupancy rates across Morning, Matinee, Evening, and Night time slots.
